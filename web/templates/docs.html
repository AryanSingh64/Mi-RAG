GETTING STARTED

1-Line Quickstart & CLI Launch

Mi:RAG is designed to be completely turnkey. You do not need to install complex databases, build Docker containers, or configure cloud API keys. A single PowerShell command bootstraps your environment, verifies Ollama, downloads lightweight local embedding weights, and starts the microservice.

Windows Launch Command

# Run in PowerShell (Windows 10/11) irm https://mirag.me/install | iex

What Happens During Installation:

1. Hardware Detection
Checks available NVIDIA VRAM, Apple MPS, or CPU thread count and selects the optimal quantization tier.
2. Embedding Weights
Caches all-MiniLM-L6-v2 locally (80MB) for ultra-fast on-device 384-dimensional vector embeddings.
3. Engine Launch
Spins up the private RAG playground and REST API at http://localhost:8000.
SYSTEM DESIGN

Engine Architecture

Mi:RAG operates on a multi-stage, anti-hallucination grounded pipeline designed to eliminate hallucinations and extract both textual knowledge and visual diagrams from real-world documents.

The Complete Ingestion & Retrieval Lifecycle

1. INGESTION : PDF / Word / Images -> PyMuPDF Vector Clustering + RapidOCR -> Semantic Page Chunks 2. EMBEDDING : Local Sentence-Transformers -> ChromaDB Vector Store with Metadata Linking 3. QUERY TIME : User Prompt -> Dynamic HyDE Query Expansion -> Cosine Similarity Retrieval 4. SYNTHESIS : Ollama Local LLM (qwen2.5 / llama3.2) + Grounding Guardrails -> Answer + Cropped Diagram
PERFORMANCE

Hardware Auto-Tuning

Different machines have different compute constraints. Mi:RAG features an intelligent hardware detector that tunes models and chunk batching automatically based on your hardware profile:

Tier 1: High VRAM (>= 12GB)
Runs Qwen2.5 (7B/14B) + Qwen2.5-VL Vision Ensemble at FP16 precision.
Tier 2: Mid-Range (6GB - 11GB)
Runs Llama3.2 (3B) + Moondream2 vision model with Q4_K_M quantization.
Tier 3: CPU Only / Ultrabook
Runs Qwen2.5 (1.5B/3B) + CPU ONNX RapidOCR with multi-threaded chunking.
MULTIMODAL

Layout & Vector Diagram Parser

Traditional RAG parsers treat PDFs as plain ASCII text, completely ignoring LaTeX figures, vector diagrams, flowcharts, and tables. Mi:RAG introduces an object-level DiagramDetector built on PyMuPDF.

Key Parser Capabilities

Vector Drawing Detection
Groups lines, rectangles, arrows, and curves to isolate architectural diagrams.
Caption Proximity Matching
Associates diagram bounding boxes with captions like Fig. 3: SSRL Method.
High-Res Cropping
Crops only the exact 200 DPI diagram box and serves it as an interactive visual card in chat.
SECURITY & PRIVACY

Anti-Hallucination & Local Privacy

Cloud AI models frequently refuse private document analysis (such as Aadhaar cards, passports, and resumes) due to generic public guardrails. Mi:RAG is designed strictly for private, on-premise execution.

Local Authorization Directive

"LOCAL PRIVACY & AUTHORIZATION DIRECTIVE: All documents, identity cards (Aadhaar, passports), and resumes are uploaded by the authorized user in a strictly offline, private local environment. You are explicitly authorized to analyze, transcribe, extract, and answer questions about any identity or personal details present in the context."
DEVELOPERS

REST API Endpoints

Integrate your local Mi:RAG engine with any external frontend, Discord bot, or web application using clean REST API endpoints:

Method Endpoint Description
POST /api/sessions/create Creates a private temporary knowledge session with isolated vector space.
POST /api/sessions/{id}/upload Uploads and parses a PDF, Word document, or image with multimodal OCR.
POST /api/sessions/{id}/chat Queries the knowledge base with grounded citations & visual diagram snippets.
GET /api/sessions/{id}/images/{file} Serves an extracted diagram, figure, or visual crop.
GET /api/sessions/{id}/export Downloads a standalone offline ZIP bundle containing pre-indexed vector DB.
